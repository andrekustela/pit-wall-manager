# Pit Wall Manager

Jogo de gestão de F1 (navegador). Vite + TypeScript no cliente, Node + WebSocket (`server/`) pro online.
Responder sempre em pt-BR (inclusive descrições de ferramentas). Usuário prefere respostas curtas e economia de tokens.

## Comandos
- `npm run dev -- --port 5179` → http://localhost:5179. ATALHO "Pit Wall - Testes" na área de trabalho do usuário → `testes.bat` (liga o dev se a 5179 estiver livre e abre `public/testes.html`: página com o EDITOR DE LANCE, as cenas do laboratório, o caos e os muros). O atalho "Pit Wall Manager" da área de trabalho é o app do Chrome do site PUBLICADO (não mostra o que não foi publicado). Um .exe da versão de teste congelaria o código: não vale pra iterar
- `npm run server` → servidor do modo online (local)
- `npm run build` → `tsc` + `tsc -p server` + vite build (rodar antes de publicar)
- `npm run sim` / `npx tsx scripts/<nome>.ts` → testes de simulação (sim-test, balance, racing-line, net-test, wreck, wobble...)
- `npx tsx scripts/i18n-left.ts <arquivos .ts>` → lista os textos que a tradução EN ainda deixa em português
- `npx tsx scripts/shot.ts <url> <pasta> "<passos>"` → screenshot headless no Edge via CDP (passos: wait:ms / shot:nome / eval:js / evalfile:C:/caminho.js / click:seletor). Caminho do evalfile no formato `C:/...` (com `/c/...` não acha). **Matar os Edge headless depois** (já acumulou 24 e travou a máquina): `Get-CimInstance Win32_Process -Filter "Name='msedge.exe'" | ? { $_.CommandLine -like '*headless*' } | % { Stop-Process -Id $_.ProcessId -Force }`

## Regras
- Sem marcas reais (Ferrari etc.) em arte/assets; nomes de pilotos oficiais ok; pistas oficiais com nomes de cidades (sem sedes atuais da F1 nem autódromos conhecidos).
- Pacotes da IA com versão fixa (piper-tts-web 1.0.5, onnxruntime-web 1.18.0, web-llm 0.2.78, transformers 3.7.6).
- Pedidos visuais costumam sair diferentes do imaginado: conferir com print (shot.ts) e perguntar o que ficou diferente.
- Na tela da corrida, o carro desenhado fica um instante ATRÁS da corrida (interpolação): efeito que nasce num evento da corrida (batida) tem que esperar o carro desenhado chegar lá (ex.: `CarFx.landed`).
- Mudar o piloto, o capacete ou as regras dos desenhos → rodar de novo `npx tsx scripts/bake-pilot.ts` (prévia 2D da aba PILOTO).
- Plus = estilos com ★ (`plus: true`); Premium ★★ = Plus + adesivos. Prévia livre; SALVAR bloqueia sem o código. Códigos em `plus-codigos.txt` (fora do git; só os hashes em `src/ui/plusCodes.ts`).
